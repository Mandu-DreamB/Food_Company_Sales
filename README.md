# 식품 매출 분석 웹사이트 (LLM 챗봇 연동)

매출 데이터와 경제 지표의 상관관계를 분석하고, LLM 챗봇을 통해 인사이트를 제공하는 웹사이트 프로젝트입니다.

## 프로젝트 로드맵

### 1단계: 지표 데이터 수집 (API 연동)

- 수집 주기: 일/월/연 단위 (검토 중)
- 수집 기간: 1년 ~ 3년 (검토 중)
- 업데이트 주기: 매일 / 매월 / 실시간 (검토 중)

> API를 통해 경제 지표 데이터를 자동으로 수집하는 파이프라인 구축

---

### 2단계: 매출/주가 vs 지표 상관관계 분석

- 매출 데이터 및 주가 흐름과 각 지표의 움직임을 비교
- 상관관계 분석을 통해 유의미한 지표 탐색

> **학습 필요:** 상관관계 분석 방법론 (Pearson, Spearman 등)

---

### 3단계: 보고서 기반 지표 키워드 추출 (RAG)

- 기업 보고서에서 매출과 연관된 지표 키워드를 자동 추출
- RAG(Retrieval-Augmented Generation) 기법 활용

> **학습 필요:** RAG 아키텍처 / LLM 기초 (현재 보류)

---

### 4단계: 매출 요인 지표 도출

- 2단계(상관관계)와 3단계(보고서 키워드)를 결합
- 실제 매출에 영향을 미치는 핵심 지표 선별

---

### 5단계: 웹사이트 구축 및 시각화

- 분석 결과를 대시보드 형태로 시각화하여 웹에 배포
- 그래프, 지표 비교 차트 등 인터랙티브 UI 제공

---

### 6단계: 고도화 (선택)

- **예측 모델:** 지표 기반 매출 예측 (성능에 따라 적용 여부 결정)
- **LLM 분석:** 자연어 기반 인사이트 자동 생성
- **챗봇:** 사용자가 질문하면 분석 결과를 답변하는 챗봇 기능
- **그래프 자동 생성:** 챗봇과 연계한 동적 차트 생성
